# 엘니뇨·라니냐 탐구실

하나의 탐구실 안에 학습 방법 세 가지가 있습니다. 첫 화면(`/`)에서 **과목(통합과학·지구과학)**을 고르면
세 학습 방법이 나오고, 학습 중에도 화면 맨 위의 탐구실 막대에서 학습 방법과 과목을 언제든 바꿀 수 있습니다.
과목별로 설명 수준과 기능을 나누는 작업은 단계별로 진행 중입니다([`docs/subject-modes.md`](docs/subject-modes.md)).

| 웹앱 | 주소 | 내용 |
| --- | --- | --- |
| 첫 화면 (과목 선택 · 학습 방법 메뉴) | `/` | 과목을 고르면 그 과목의 학습 방법 메뉴. 고른 과목은 이 기기의 브라우저(localStorage)에만 저장 |
| 개념 시뮬레이션 | `/simulation/` | 지구과학Ⅰ 「대기와 해양의 상호 작용」 수업용 시뮬레이션. 평상시·엘니뇨·라니냐는 실측 자료(평년·실제 사례 평균)에 맞췄고, 무역풍을 바꾸면 바다가 몇 달에 걸쳐 따라 바뀜. ③ 그래프는 1991~2024 실측 자료 |
| 실측자료 탐구 (엘니뇨·라니냐 실측자료 탐구실, Pacific ENSO Observatory) | `/observatory/` | 엘니뇨 3개(1997~1998, 2015~2016, 2023~2024)와 라니냐 2개(1998~1999, 2020~2022) 사례의 **실제 관측·재분석 자료**로 해수면 온도, 적도 수온 단면, 무역풍, 강수량을 탐구 |
| 대화형 학습 (대화로 배우는 엘니뇨) | `/story/` | 무역풍·서태평양 바다·동태평양 바다·구름·페루 어부의 대화를 따라가며 엘니뇨가 생기는 까닭과 영향을 배우는 페이지. 그림은 개념 시뮬레이터의 모형(`js/model.js`)과 그리기 코드(`js/draw.js`)를 그대로 씀 |

## 과목별 바로 가기 주소

구글 클래스룸 등에 과목별 링크를 걸 수 있습니다(`<주소>`는 배포한 탐구실 주소).

| 링크 | 열리는 화면 |
| --- | --- |
| `<주소>/?subject=integrated` | 통합과학 학습 방법 메뉴 |
| `<주소>/?subject=earth` | 지구과학 학습 방법 메뉴 |
| `<주소>/?subject=integrated&learn=story` · `…&learn=sim` · `…&learn=data` | 통합과학 대화형 학습 · 개념 시뮬레이션 · 실측자료 탐구 |
| `<주소>/?subject=earth&learn=story` · `…&learn=sim` · `…&learn=data` | 지구과학 대화형 학습 · 개념 시뮬레이션 · 실측자료 탐구 |

- 링크로 들어오면 과목 선택 화면을 건너뛰고 그 과목이 저장됩니다. 학습 페이지 주소에 직접 `?subject=`를 붙여도 됩니다(예: `/story/?subject=earth`).
- 예전 주소도 그대로 열립니다: `/#compare`, `/#so`, `/#wind`는 개념 시뮬레이션(`/simulation/`)의 같은 탭으로 옮겨 가고, `/story/`, `/observatory/`는 그대로입니다.

## 엘니뇨·라니냐 실측자료 탐구실 (`observatory/`)

- 위에서 **엘니뇨 / 라니냐**를 고르면 그 현상의 대표 사례가 나옵니다.

  | 사례 | NOAA 공식 발생 기간 (RONI) | 자료 탐색 기간 |
  | --- | --- | --- |
  | 1997~1998년 엘니뇨 | 1997.4~1998.4 | 1996.1~1999.12 |
  | 2015~2016년 엘니뇨 | 2014.11~2016.4 | 2014.1~2017.12 |
  | 2023~2024년 엘니뇨 | 2023.7~2024.2 | 2022.1~2024.12 |
  | 1998~1999년 라니냐 | 1998.6~2000.6, 2000.10~2001.3 | 1998.1~2001.6 |
  | 2020~2022년 라니냐 | 2020.5~2023.3 | 2020.1~2023.6 |

- 날짜 옆의 **엘니뇨·라니냐·중립** 표시와 슬라이더 아래 색 띠, 시계열 음영은 NOAA CPC가 공식 감시에 쓰는 RONI 표의 판정(빨강·파랑)을 그대로 옮긴 것입니다. 라니냐 사례 안에서도 발생 전·후 달은 중립(또는 앞선 엘니뇨)으로 나옵니다. 월별 Niño 3.4 편차만으로 판정하지 않습니다.
- 사례를 고르고 시간 슬라이더(월 단위, 자동 재생)를 움직이면 지도·바람 화살표·수온 단면·20 ℃ 등온선·관측값·시계열이 모두 같은 연·월 자료로 바뀝니다.
- **지도**(30°S~30°N, 100°E~70°W 고정): 해수면 온도 또는 강수량, 실제 값/평년 편차 전환, 10 m 바람 화살표. 누르면 그 격자의 값을 보여 주고, 단면 영역(2°S~2°N) 안을 누르면 단면에도 같은 경도가 표시됩니다.
- **수온 단면**(2°S~2°N 평균, 0~500 m): 실제 수온/수온 편차, 20 ℃ 등온선(실선 그 달, 점선 같은 달 평년). 누르면 그 경도의 등온선 깊이와 평년과의 차이, 평균에 쓴 해양 격자 수를 보여 줍니다. 위도 평균은 값이 있는 해양 격자만 쓰며, 해양 격자가 12개 중 6개 미만인 칸은 빗금으로 표시합니다.
- **시기 비교**: 두 연·월을 같은 색 범위·같은 수심 축으로 나란히 봅니다. 서로 다른 현상끼리도 됩니다(예: 2022년 12월 라니냐 ↔ 2023년 12월 엘니뇨, 1997년 12월 엘니뇨 ↔ 1999년 12월 라니냐).
- **시계열**(접이식): Niño 3.4 수온 편차와 선택 해역의 10 m 동서 바람.
- 자료는 `observatory/data/*.json`을 읽으므로 **웹 서버로 열어야** 합니다(파일을 바로 열면 자료를 읽지 못함). Vercel·GitHub Pages에 올리면 그대로 동작합니다.

| 화면 요소 | 자료 | 해상도 | 받는 곳 |
| --- | --- | --- | --- |
| 해수면 온도, Niño 3.4 | NOAA ERSST v5 | 2°, 월 | www.ncei.noaa.gov |
| 수온 단면, 20 ℃ 등온선 | NCEP GODAS 잠재 수온 | 경도 1° × 위도 1/3°, 40층 | downloads.psl.noaa.gov |
| 바람 화살표, 무역풍 | NCEP/NCAR Reanalysis 1 10 m u·v | T62(약 1.9°) | downloads.psl.noaa.gov |
| 강수량 | GPCP Monthly v2.3 | 2.5° | NOAA CDR(AWS 공식 사본) |
| 엘니뇨·라니냐 공식 판정 | NOAA CPC RONI 표(공식), 참고 ONI v5 표 | 계절(3개월) | www.cpc.ncep.noaa.gov |

평년은 모두 1991~2020년 같은 달 평균을 원자료에서 직접 계산했습니다. 자료 만들기·검증 방법은 [`pipeline/README.md`](pipeline/README.md), 검증 결과는 [`pipeline/validation/REPORT.md`](pipeline/validation/REPORT.md)를 보세요.
검증 요약: Niño 3.4 편차가 NOAA CPC 공식 값과 408개월 모두 0.03 °C 이내, 2023년 12월 적도 수온 편차 단면이 CPC 월간 해양 브리핑 그림과 같은 모습, 같은 R1 자료로 계산한 850 hPa 무역풍 지수가 CPC 공식 지수와 상관 0.998 이상.

### 자료 다시 만들기

```bash
cd pipeline
pip install -r requirements.txt
./run_all.sh     # 내려받기 → 가공 → observatory/data/*.json → 검증 보고서
```

### Vercel 배포

빌드 과정이 없는 정적 사이트입니다. Vercel에서 이 저장소를 가져와(Framework Preset: Other, Build Command 비움, Output Directory 비움 = 저장소 루트) 배포하면
`/`는 개념 시뮬레이터, `/observatory/`는 실측자료 탐구실로 열립니다. 월별 자료는 연도별 파일(`observatory/data/year-YYYY.json`, 15개)이라 사례 기간이 겹쳐도 한 번만 저장됩니다. 사례 하나를 열 때 3~4개 파일(압축 약 1.2~1.5 MB)을 받습니다.

## 대화로 배우는 엘니뇨 (`story/`)

- 통합과학 수준으로 만든 대화형 페이지입니다. 통합과학에 나오지 않는 **남방진동·워커 순환이라는 용어는 쓰지 않고**, 공기의 오르내림과 구름·비는 그림과 대사로만 보여 줍니다.
- 캐릭터 다섯: 무역풍, 서태평양 바다, 동태평양 바다, 구름, 페루 어부. 말하는 캐릭터는 그림 위에서 노란 테두리로 표시되고, 대사가 설명하는 곳은 그림에서 밝게 비춥니다.
- 단계 (STEP 0~7)

  | STEP | 내용 |
  | --- | --- |
  | 0 | 같은 적도, 다른 바다 (서쪽은 따뜻하고 동쪽은 차가움) |
  | 1 | 무역풍이 따뜻한 표층 바닷물을 서쪽으로 밀어 서쪽 해수면이 높고 따뜻한 물의 층이 두꺼움, 수온약층 |
  | 2 | 동쪽의 용승과 어장 |
  | 3 | 따뜻한 바다 위는 공기가 올라가 구름·비, 차가운 바다 위는 공기가 내려와 맑고 건조 |
  | 4 | 무역풍이 약해지면? **먼저 예측**한 뒤 그림이 바뀌고, 엘니뇨라는 이름을 알려 줌 |
  | 5 | 엘니뇨의 영향: 어획량 감소, 이름의 유래, 강수 지역 변화(홍수·가뭄·산불) |
  | 6 | 평상시와 엘니뇨를 번갈아 보며 정리 |
  | 7 | **도전**: 무역풍이 강해지면? 예측한 뒤 마지막에 라니냐라는 이름만 알려 줌 (교과서 밖 내용이라 '도전'으로 표시) |

- 마지막 버튼은 같은 통합과학용인 실측자료 탐구실(`observatory/`)로 이어집니다.
- 대사는 `story/js/script.js`의 `STEPS`만 고치면 됩니다. 대사마다 상태 `s`, 나타날 그림 층(`show`), 밝게 비출 곳(`hl`), 핵심 정리(`key`), 예측 문제(`ask`)를 적습니다. 형식은 파일 맨 위 주석에 있습니다.
- 수온·수온약층·해수면·용승·구름 위치는 개념 시뮬레이터와 같은 `js/model.js`로 계산합니다. 평년과 실제 사례 평균에 맞춘 모형 값이며 어느 한 해의 관측값은 아니라고 화면에 적어 두었습니다. 엘니뇨 때 남아메리카 해안의 비구름은 모형의 동태평양 연안 표층 수온이 26.5 °C 이상일 때만 그립니다.
- 키보드: →·Space·Enter 다음, ← 이전. 운영 체제의 '동작 줄이기'가 켜져 있으면 움직임이 꺼진 채 시작합니다.

# 개념 시뮬레이션 (`simulation/`)

지구과학Ⅰ 「대기와 해양의 상호 작용」 단원(엘니뇨와 라니냐, 남방진동) 수업용 웹앱입니다.
글은 최소로 줄이고 그림과 조작 위주로 만들었습니다. 평상시·엘니뇨·라니냐의 모습은 실측자료 탐구실과 같은 공식 자료로 맞춘 시뮬레이션입니다.

## 여는 방법

- **바로 열기**: 저장소의 `index.html`(첫 화면) 또는 `simulation/index.html`을 브라우저로 엽니다. 설치나 서버가 필요 없습니다(실측자료 탐구실만 웹 서버가 필요).
- **웹 주소로 쓰기**: 저장소의 Settings → Pages에서 배포 브랜치를 고르면 학생들이 주소로 접속할 수 있습니다.
- `simulation/` 주소 끝에 `#compare`, `#so`를 붙이면 해당 탭이 바로 열립니다(①은 주소 그대로, `#wind`도 ①로 열림). 예전 주소 `/#compare` 등은 첫 화면이 이 주소로 옮겨 줍니다. 새로고침해도 보던 탭이 그대로 열립니다.
- 글꼴(IBM Plex Sans KR)은 Google Fonts에서 받아 오며, 인터넷이 없으면 기기에 있는 한글 글꼴로 표시됩니다.

## 탭 구성

| 탭 | 하는 일 |
| --- | --- |
| ① 무역풍 실험 | 무역풍 세기를 슬라이더로 바꾸면 바람은 곧바로 바뀌고, 바다는 **몇 달에 걸쳐** 따라 바뀝니다. 변화가 퍼지는 앞머리(노란 점)와 '바람이 바뀐 뒤 ○개월' 시계, 아직 바뀌는 중인 원인·결과 고리의 깜빡임이 보입니다. 화살표의 길이·방향은 경도마다 실측 바람의 세기를 따릅니다. **20 ℃ 등온선**(굵은 실선)과 평상시 20 ℃ 등온선(점선)을 강조하고, 나머지 등온선은 `모든 등온선`으로 켭니다. 오른쪽에는 핵심 정보만 두고 나머지는 접이식 `상세 정보`에 넣었습니다. **실제 관측 바람으로 실험하기**(고급 탐구, 펼쳐서 사용)는 사례 기간의 실제 무역풍(NCEP/NCAR R1)으로 모형의 바다를 움직이고, 연·월, NOAA 공식 판정, 모형과 실제 감시 구역 수온 편차를 나란히 보여 줍니다. |
| ② 세 상태 비교 | 평상시(1991~2020 평년)·엘니뇨(실제 사례 3개 평균)·라니냐(실제 사례 2개 평균)의 단면을 같은 색 범위·같은 수심 축으로 나란히 봅니다. 대기 순환은 `대기 순환`으로 켭니다. `평상시와의 차이`로 바꾸면 수온 편차(°C)로 칠해지고, 그림 위를 누르거나 움직이면 모든 그림의 같은 경도를 함께 비교합니다. 아래 표는 핵심 항목을 먼저 보여 주고, 기압·날씨 변화는 펼쳐 봅니다. |
| ③ 대기 순환과 남방진동 | 실제 해안선(Natural Earth) 위에 대기 순환(워커 순환, 교육용 모형)을 그리고, 다윈·타히티 기압 시소, 남방진동 지수, **1991~2024 실측 시계열**(엘니뇨 감시 구역 수온 편차: ERSST v5, 남방진동 지수: NOAA CPC 3개월 평균, 음영: NOAA CPC 공식 판정) 순서로 보여 줍니다. 그래프에서 달을 고르거나 `시간 흐름 재생`을 누르면 지도는 그 달의 수온 편차에 맞춘 모형 상태로, 기압 시소는 그 달의 실제 다윈·타히티 기압 편차(hPa)로 바뀌며, 시소 제목 옆에 `모형 값`/`실측 · 연월`을 표시합니다. |

과목에 따라 보여 주는 범위가 다릅니다(첫 화면이나 맨 위 막대에서 고른 과목, 고르지 않았으면 지구과학).

## 과학적 근거와 단순화

평상시·엘니뇨·라니냐의 값은 `pipeline/build_sim.py`가 실측자료 탐구실의 자료(`observatory/data/`)와 NOAA CPC 기압 자료로 만든
`js/obs-calib.js`에서 읽습니다. 그 사이 상태와 시간 변화는 단순한 모형입니다.

- **상태 s**: −1 = 엘니뇨 합성(1997~98, 2015~16, 2023~24 사례의 정점 달 앞뒤 1개월 평균 편차를 사례마다 구해 평균), 0 = 1991~2020 연평균 평년,
  +1 = 라니냐 합성(1998~2001, 2020~23 사례, 같은 방법). 사이 값은 평년값 + 합성 편차 × |s|(선형). 버튼의 엘니뇨·라니냐는 s = ∓1입니다.
  실제 라니냐가 엘니뇨보다 약하므로(감시 구역 편차 +2.3 °C 대 −1.3 °C) 그림에서도 라니냐의 변화가 작습니다.
- **수온 단면**: GODAS 2°S~2°N 평균(130~280°E, 2° 간격, 0~366 m) 연평균 평년값과 합성 편차를 **깊이마다 경도 방향으로 가우스 평활화(σ = 8°)**해서 씁니다(`js/model.js`의 `SMOOTH_LON`, 원값은 `E.RAW_SECTION`). 평활화는 선형이라 평상시·엘니뇨·라니냐와 그 사이 상태가 같은 방식으로 다듬어지고, 색·등온선·20 °C 깊이·혼합층이 모두 이 수온장 하나에서 계산됩니다. 깊이 방향은 다듬지 않습니다. 표층 상태와 아래쪽(60 m 아래) 상태를 깊이에 따라 섞고, 시간 변화 중 아래쪽이 먼저 데워질 때는 위층보다 따뜻해지지 않게 맞춥니다(정적 안정).
  20 °C 등온선(수온 약층 대표 깊이)은 평상시 서(150°E) 약 176 m·동(90°W) 약 36 m, 엘니뇨 약 150 m·85 m, 라니냐 약 196 m·23 m입니다.
  수온 약층 시작 깊이(혼합층 바닥)는 표층보다 0.5 °C 낮아지는 깊이로, 평상시 서 약 59 m·동 약 11 m입니다.
  평활화 전후 비교(서·동 20 °C 깊이 / 단면 표층 수온): 평상시 178·34 m → 176·36 m, 엘니뇨 150·82 m → 150·85 m, 라니냐 197·20 m → 196·23 m, 단면 표층 수온 변화 0.3 °C 이내.
  등온선의 작은 굴곡(경도 1° 간격 총변동)은 20 °C선 기준 평상시 176 → 148 m, 엘니뇨 114 → 74 m, 라니냐 208 → 180 m로 줄었고, 원 합성 자료에 있던 작은 수온 역전(엘니뇨 4칸, 라니냐 18칸, 최대 수백분의 1 °C)은 0칸이 됐습니다. ERSST 표층 수온·감시 구역 편차·바람·강수·기압 값은 바뀌지 않습니다.
- **표층 수온**: ERSST v5 2°S~2°N(바다 격자만). 평상시 서 약 29.8 °C·동 약 24.9 °C, 엘니뇨 때 동 약 +2.6 °C(140~110°W에서 약 +3 °C)·서 약 −0.2 °C,
  라니냐 때 중앙 태평양 약 −1.4 °C·동 약 −0.9 °C·서 약 +0.2 °C. 엘니뇨 감시 구역(5°S~5°N, 170°W~120°W) 편차는 합성값 +2.3 °C(엘니뇨)·−1.3 °C(라니냐)에 맞춥니다.
- **무역풍**: NCEP/NCAR R1 10 m 동서 바람. 세기 비율은 서·중앙 태평양(5°S~5°N, 135°E~140°W) 평균으로 엘니뇨 때 평상시의 약 60 %, 라니냐 때 약 139 %입니다.
  그림의 화살표는 경도마다 적도(5°S~5°N) 평년 바람 + 합성 편차의 세기·방향입니다. 용승은 바람 응력(풍속²)에 비례하게 두고, 물고기 수는 용승 세기와 동태평양 수온 약층 깊이(얕을수록 영양염이 많은 물이 올라옴)로 정합니다.
- **해수면**: 실측 해수면 자료는 쓰지 않고, 따뜻한 층이 두꺼운 곳일수록 해수면이 높다는 관계(η ≈ Δρ/ρ × 20 °C 등온선 깊이, Δρ/ρ ≈ 0.0032)로 계산합니다.
  평상시 서−동 차 약 45 cm(실제 약 40~50 cm), 엘니뇨 약 21 cm, 라니냐 약 55 cm. 그림에서는 과장해서 그립니다.
- **시간 변화(①)**: 무역풍이 바뀌면 175°E에서 시작한 수온 약층의 변화가 동쪽으로 약 60°/월(≈ 2.6 m/s, 적도 켈빈파 속도), 서쪽으로 약 20°/월(로스비파)로 퍼지고,
  수온 약층은 약 0.7개월, 표층 수온은 그보다 약 1개월 늦게 따라갑니다(1초 = 1개월, 재생은 1초 = 1.6개월). 바다가 대기에 되먹임하는 과정은 넣지 않았습니다.
  1991~2024 실제 무역풍(앞 3개월 평균)으로 돌렸을 때 모형의 감시 구역 수온 편차는 실측과 상관계수 약 0.8, 평균 오차 약 0.7 °C입니다.
  1997~98년처럼 잘 맞는 시기도 있고, 라니냐의 세기나 엘니뇨가 시작되는 시점이 실제와 다른 시기도 있으므로 화면에 모형 값과 실제 값을 함께 보여 줍니다.
- **엘니뇨·라니냐 판정**: 모형 그림의 딱지는 감시 구역 수온 편차 ±0.5 °C 기준입니다. 실제 판정은 이런 상태가 몇 달 이상 계속되어야 하며, ①의 재생과 ③의 그래프에는 NOAA CPC 공식 판정(RONI)을 표시합니다.
- **워커 순환**: 상승 기류(구름·비) 중심 경도는 GPCP 강수(5°S~5°N, 월 100 mm 넘는 비의 무게 중심)로 평상시 약 156°E, 엘니뇨 약 192°E(170°W), 라니냐 약 144°E입니다.
  상승 기류 세기는 강수 최댓값의 비율로 정합니다. 순환 고리의 세기는 모식입니다.
- **남방진동**: 다윈·타히티 해면 기압(NOAA CPC) 편차(1991~2020 평년 대비)의 합성은 엘니뇨 때 다윈 +1.3 hPa·타히티 −0.8 hPa(남방진동 지수 −1.0),
  라니냐 때 다윈 −0.6 hPa·타히티 +1.3 hPa(지수 +1.2)입니다. ③의 그래프에서 달을 고르면 그 달의 실제 기압 편차(앞뒤 1개월 평균)를 씁니다.

## 접근성

- 키보드로 탭(←/→), 슬라이더, 버튼을 모두 조작할 수 있습니다. ③의 시계열 그래프도 선택한 뒤 ←/→(한 달), PageUp/PageDown(1년), Home/End로 시기를 옮길 수 있습니다.
