# 과목별 학습 모드 개편 — 설계와 진행표

하나의 「엘니뇨·라니냐 탐구실」에서 과목(통합과학·지구과학)을 고르고, 같은 세 학습 방법(대화형 학습·개념 시뮬레이션·실측자료 탐구)을
과목 수준에 맞게 쓰도록 바꾸는 작업이다. 새 웹앱을 만들지 않고 기존 세 웹앱에 과목별 모드를 적용한다.
한 번의 요청에서 한 단계만 구현·검증하고 멈춘다.

## 진행표

- [x] **1단계 — 공통 학습 구조** (첫 화면 과목 선택, 과목별 학습 메뉴, localStorage, 과목 변경, 바로 가기 주소, 페이지 간 이동)
- [x] **2단계 — 개념 시뮬레이션** (통합과학·지구과학 모드, 20 ℃ 등온선 강조, 표시용 수온장 평활화, 정보 패널 간소화, 실제 바람 재생 분리, ③ 탭 이름 「대기 순환과 남방진동」)
- [x] **3단계 — 대화형 학습** (통합과학: 라니냐 도전 단계 숨김 / 지구과학: 라니냐·워커 순환·남방진동 PART 추가, 과목별 단계 분기)
- [x] **4단계 — 실측자료 탐구** (통합과학 간단 모드: 엘니뇨 사례·지도 중심 / 지구과학: 전체 기능 유지)
- [x] **5단계 — 통합 점검** (과목별 학습 흐름, 이동·설정 유지, 링크 호환, 화면 크기, 과학적 정확성, 회귀 테스트, 수정 전후 스크린샷)

(1~4단계 뒤에 첫 화면 과목 선택 디자인을 Pacific Blue 색으로 바꿈: `css/hub.css`. 그 뒤 그림을 빼고 과목명·학습 내용 중심 카드로 정리했고, 화면 과목명을 '통합과학2'로 고침 — 식별자 `integrated`는 그대로)

## 1단계에서 만든 구조

```
/                  index.html — 첫 화면: 과목 선택 → 그 과목의 학습 방법 메뉴
/simulation/       개념 시뮬레이션 (예전 루트 index.html을 옮김. css/js 는 ../ 로 공유)
/story/            대화형 학습
/observatory/      실측자료 탐구
js/lab.js          공통 과목 상태(window.LAB)와 학습 페이지 맨 위 탐구실 막대
css/lab.css        탐구실 막대(자체 색 토큰 --lab-*)
css/hub.css        첫 화면 디자인(Pacific Blue 색 토큰을 body.hub-page 안에서만, 글 중심 과목 카드)
```

- **과목 상태**: `?subject=integrated|earth`가 주소에 있으면 우선하고 저장, 없으면 localStorage `enso-lab-subject`.
  서버로 보내지 않는다. `<html data-subject>`를 `<head>`에서 바로 붙인다.
- **과목이 바뀔 때**: 페이지는 그대로 머물고 `window`에 `lab:subject` 이벤트(`detail.subject`)가 간다. `LAB.onChange(fn)`도 된다.
  2~4단계에서 각 학습 페이지가 이 속성·이벤트로 내용을 바꾼다(1단계에서는 아직 내용이 바뀌지 않는다).
- **탐구실 막대**: `<html data-lab="story|sim|data">`인 페이지 맨 위. 왼쪽 「엘니뇨·라니냐 탐구실 / 학습 메뉴」(첫 화면),
  오른쪽 학습 방법 메뉴(세 방법, 지금 보는 곳 표시)와 과목 메뉴(통합과학·지구과학). Esc로 닫고 ↓/↑로 이동.
- **바로 가기 주소**: `/?subject=integrated`, `/?subject=earth`, `&learn=story|sim|data`. 예전 `/#wind|#compare|#so`는 `/simulation/`의 같은 탭으로.
  과목 없이 학습 페이지에 바로 들어오면 막대에 「과목 선택」이 보이고 페이지는 지금처럼 동작한다.

## 2단계에서 바꾼 것 (개념 시뮬레이션)

- 수온장: 실측 단면(평년·합성 편차)을 깊이마다 경도 방향 가우스 평활화(σ = 8°). 색·등온선·20 ℃ 깊이·혼합층이 같은 수온장에서 나온다.
  전후: 서·동 20 ℃ 깊이 평상시 178·34 → 176·36 m, 엘니뇨 150·82 → 150·85 m, 라니냐 197·20 → 196·23 m. 수온 역전 0칸.
  시간 변화 중 생기던 역전(최대 0.45 ℃)은 정적 안정 처리로 없앰. ERSST 표층 수온·감시 구역 편차·바람·강수·기압은 그대로.
- 20 ℃ 등온선 굵은 실선 + 평상시 20 ℃ 점선, 다른 등온선은 '모든 등온선'(지구과학, 기본 끔).
- 통합과학: ①·② 두 탭, 무역풍 평상시~약화, 기본 정보(무역풍 세기·표층 수온·용승·비가 많이 오는 곳), 비구름, 평상시·엘니뇨 두 그림.
- 지구과학: 세 탭, 기본 정보(표층 수온·20 ℃ 깊이·용승 강도) + 접이식 상세 정보, '실제 관측 바람으로 실험하기' 고급 탐구 영역,
  ② 워커 순환 기본 끔·표 핵심/펼침, ③ 「대기 순환과 남방진동」·모형/실측 표시.

## 3단계에서 바꾼 것 (대화형 학습)

- 대본을 과목별로: `STORY.stepsFor(과목)`, 단계 `id`·`part`·`only`, 대사 `only`·과목별 말. 공통 대사는 함께 쓰고 수온약층 관련 대사 2개만 과목별 말로 나눔.
- 통합과학: STEP 0~6(라니냐 도전 단계 숨김), 제외 용어 없음(자동 점검), 예측 1개 유지, 그림은 '따뜻한 해수층'과 경계선.
- 지구과학: PART A 기본 원리(6단계, 수온약층·20 ℃ 등온선 대사 2개 추가) · B 라니냐(3) · C 워커 순환(4) · D 남방진동(5), 예측 6개.
  PART 막대로 이동, 새 그림 층 walker(워커 순환 고리)·pressure(다윈·타히티 기압 편차, 모형)·soi(남방진동 지수, 모형).
- 과목을 바꾸면 같은 단계(없으면 앞쪽 가장 가까운 단계)에서 이어 감. 오른쪽 위 '실제 관측 자료로 보기' 버튼은 탐구실 막대와 겹쳐 뺌.

## 4단계에서 바꾼 것 (실측자료 탐구)

- 통합과학: 엘니뇨 사례 3개, 지도(해수면 온도·강수량, 실제 값·평년 편차, 바람 화살표), 월별 재생, 엘니뇨 시기 표시·엘니뇨 기간 띠,
  시기 비교(엘니뇨 사례만, 지도만), 탐구 순서 안내, 간단한 자료 출처. 라니냐 사례·수온 단면·시계열·Niño 3.4·공식 판정 상세는 숨김.
- 지구과학: 전체 기능 그대로(GODAS 위도 평균·대표성 빗금 포함).
- 자료 값은 두 과목에서 같음(같은 곳을 눌러 값 비교로 확인). 과목을 바꾸면 그 자리에서 화면이 바뀌고, 라니냐 사례를 보던 중이면 엘니뇨 사례로.

## 5단계 통합 점검 결과

기준: 개편 전 `main`(4ab2a57)과 지금을 비교. Playwright(Chromium)로 확인.

- **세 웹앱 간 이동·과목 유지**: 첫 화면 → 학습 메뉴 → 대화형 → (막대) 시뮬레이션 → 실측자료, 실측자료에서 과목을 바꾼 뒤
  시뮬레이션·대화형으로 옮겨도 바꾼 과목 유지, 새로고침 유지, 막대 「탐구실」 → 그 과목의 학습 메뉴, '과목 바꾸기'에 지금 과목 표시.
  대화형 진행 중 과목을 바꾸면 페이지에 머물고 주소의 `?subject=`도 고쳐짐.
- **직접 링크**: `/?subject=integrated|earth`, `/?subject=…&learn=story|sim|data`(6가지), 예전 `/#wind`·`/#compare`·`/#so`·`/index.html#compare`,
  통합과학 `simulation/#so` → ①, 과목 없이 학습 페이지 직접(막대에 「과목 선택」, 시뮬레이션·실측자료는 전체 기능, 대화형은 통합과학 대본),
  잘못된 `?subject=` 무시, 과목 저장 뒤 `/?learn=sim`.
- **필수 검증**: 통합과학 무역풍 약화↔평상시·② 두 그림·실제 엘니뇨 사례 수온·강수, 지구과학 무역풍 −100~100·② 세 그림·
  20 ℃ 깊이(동쪽 라니냐 < 엘니뇨)·모든 등온선·③ 기압 시소(다윈·타히티, 엘니뇨/라니냐에서 바늘이 다름)·대화형 PART A~D, 통합과학 화면·대본 제외 용어 없음.
- **자료 값**: `observatory/data/`, `js/obs-calib.js`, `pipeline/`, `js/land.js`는 개편 전과 바이트 단위로 같음.
  모형의 ERSST 표층 수온·Niño 3.4(+2.31/0/−1.26 °C)도 같고, 바뀐 것은 단면 평활화에 따른 20 °C 깊이·혼합층·해수면 차(README 「과학적 근거」에 적은 값과 일치)뿐.
- **화면 크기**: 휴대폰 375·태블릿 820·노트북 1366×768·프로젝터 1280×720·1024×768 × 밝은·어두운 × 두 과목에서 첫 화면(과목 선택·메뉴),
  시뮬레이션 ①②③, 대화형 처음·마지막, 실측자료 기본·시기 비교: 콘솔 오류·404·가로 넘침 0. 막대의 두 메뉴가 화면 안(320~820px 확인).
  가장 작은 화면 글자는 노트북·프로젝터에서 11 px(드롭다운 ▾ 표시·색 막대 눈금, ③ 기압 범례 원 안의 ▲ 기호만 10 px), 캔버스 글자 제외.
- **이번 점검에서 고친 것**: 휴대폰에서 학습 방법 메뉴가 오른쪽 화면 밖으로 24 px 나가던 문제(두 메뉴를 막대 오른쪽 끝에 맞춤),
  엘니뇨 감시 구역 눈금 글자 10.5 → 11.5 px.
- **회귀 점검**: 1단계 37 · 2단계 26 · 3단계 14 · 4단계 16 · 5단계 42 항목 통과, eslint `no-undef` 통과.
