# 과목별 학습 모드 개편 — 설계와 진행표

하나의 「엘니뇨·라니냐 탐구실」에서 과목(통합과학·지구과학)을 고르고, 같은 세 학습 방법(대화형 학습·개념 시뮬레이션·실측자료 탐구)을
과목 수준에 맞게 쓰도록 바꾸는 작업이다. 새 웹앱을 만들지 않고 기존 세 웹앱에 과목별 모드를 적용한다.
한 번의 요청에서 한 단계만 구현·검증하고 멈춘다.

## 진행표

- [x] **1단계 — 공통 학습 구조** (첫 화면 과목 선택, 과목별 학습 메뉴, localStorage, 과목 변경, 바로 가기 주소, 페이지 간 이동)
- [x] **2단계 — 개념 시뮬레이션** (통합과학·지구과학 모드, 20 ℃ 등온선 강조, 표시용 수온장 평활화, 정보 패널 간소화, 실제 바람 재생 분리, ③ 탭 이름 「대기 순환과 남방진동」)
- [ ] **3단계 — 대화형 학습** (통합과학: 라니냐 도전 단계 숨김 / 지구과학: 라니냐·워커 순환·남방진동 PART 추가, 과목별 단계 분기)
- [ ] **4단계 — 실측자료 탐구** (통합과학 간단 모드: 엘니뇨 사례·지도 중심 / 지구과학: 전체 기능 유지)
- [ ] **5단계 — 통합 점검** (과목별 학습 흐름, 이동·설정 유지, 링크 호환, 화면 크기, 과학적 정확성, 회귀 테스트, 수정 전후 스크린샷)

## 1단계에서 만든 구조

```
/                  index.html — 첫 화면: 과목 선택 → 그 과목의 학습 방법 메뉴
/simulation/       개념 시뮬레이션 (예전 루트 index.html을 옮김. css/js 는 ../ 로 공유)
/story/            대화형 학습
/observatory/      실측자료 탐구
js/lab.js          공통 과목 상태(window.LAB)와 학습 페이지 맨 위 탐구실 막대
css/lab.css        탐구실 막대(자체 색 토큰 --lab-*)와 첫 화면 디자인
```

- **과목 상태**: `?subject=integrated|earth`가 주소에 있으면 우선하고 저장, 없으면 localStorage `enso-lab-subject`.
  서버로 보내지 않는다. `<html data-subject>`를 `<head>`에서 바로 붙인다.
- **과목이 바뀔 때**: 페이지는 그대로 머물고 `window`에 `lab:subject` 이벤트(`detail.subject`)가 간다. `LAB.onChange(fn)`도 된다.
  2~4단계에서 각 학습 페이지가 이 속성·이벤트로 내용을 바꾼다(1단계에서는 아직 내용이 바뀌지 않는다).
- **탐구실 막대**: `<html data-lab="story|sim|data">`인 페이지 맨 위. 왼쪽 「엘니뇨·라니냐 탐구실 / 학습 메뉴」(첫 화면),
  오른쪽 학습 방법 메뉴(세 방법, 지금 보는 곳 표시)와 과목 메뉴(통합과학·지구과학). Esc로 닫고 ↓/↑로 이동.
- **바로 가기 주소**: `/?subject=integrated`, `/?subject=earth`, `&learn=story|sim|data`. 예전 `/#wind|#compare|#so`는 `/simulation/`의 같은 탭으로.
  과목 없이 학습 페이지에 바로 들어오면 막대에 「과목 선택」이 보이고 페이지는 지금처럼 동작한다.

## 2단계에서 바꾼 것 (개념 시뮬레이션)

- 수온장: 실측 단면(평년·합성 편차)을 깊이마다 경도 방향 가우스 평활화(σ = 8°). 색·등온선·20 ℃ 깊이·혼합층이 같은 수온장에서 나온다.
  전후: 서·동 20 ℃ 깊이 평상시 178·34 → 176·36 m, 엘니뇨 150·82 → 150·85 m, 라니냐 197·20 → 196·23 m. 수온 역전 0칸.
  시간 변화 중 생기던 역전(최대 0.45 ℃)은 정적 안정 처리로 없앰. ERSST 표층 수온·감시 구역 편차·바람·강수·기압은 그대로.
- 20 ℃ 등온선 굵은 실선 + 평상시 20 ℃ 점선, 다른 등온선은 '모든 등온선'(지구과학, 기본 끔).
- 통합과학: ①·② 두 탭, 무역풍 평상시~약화, 기본 정보(무역풍 세기·표층 수온·용승·비가 많이 오는 곳), 비구름, 평상시·엘니뇨 두 그림.
- 지구과학: 세 탭, 기본 정보(표층 수온·20 ℃ 깊이·용승 강도) + 접이식 상세 정보, '실제 관측 바람으로 실험하기' 고급 탐구 영역,
  ② 워커 순환 기본 끔·표 핵심/펼침, ③ 「대기 순환과 남방진동」·모형/실측 표시.

| | 통합과학 | 지구과학 |
| --- | --- | --- |
